# Public Gateway

Independent public records research website, not affiliated with any government agency.

## Approved design
Midnight navy, metallic gold, white and light gray; classical courthouse logo without registered mark; subtle US flag in upper-right hero only; serif headings, clean body text; flat rectangular cards, photographic feature panels, traditional desktop navigation, responsive mobile website. Headline: Your Gateway to Public Records. No unapproved redesigns.

## Architecture
Portable static HTML/CSS/JS; no paid APIs or accounts. GitHub Pages development preview. Nationwide scope; initial federal and Texas resources. Clearly distinguish planned coverage from available coverage. Verify links and access requirements before commercial launch. Do not collect personal records. Commercial hosting and advertising eligibility must be addressed before monetization.
